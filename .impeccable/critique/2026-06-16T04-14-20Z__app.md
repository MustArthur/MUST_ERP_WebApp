## Overall Impression

System logic is solid but design layer is unprocessed AI scaffold. Biggest opportunity: persistent sidebar navigation replaces homepage-as-launcher and eliminates 2+ clicks per cross-module action.

## What's Working

1. Thai-first functional UI — buttons, modals, validation messages all in Thai

## Priority Issues

### [P1] No persistent sidebar navigation
Why: QC/production workers switch modules repeatedly per shift; current "home → module → home → module" adds 2 clicks every time.
Fix: Add persistent left sidebar grouping modules by workflow phase.
Command: /impeccable shape sidebar-navigation

### [P1] "PHASE 0/1/2/3/4" numbered markers on homepage
Why: Absolute ban — numbered scaffolding that carries no information.
Fix: Remove PHASE labels. Use phase name + visual separator only.
Command: /impeccable polish homepage

### [P1] Zero brand identity — default shadcn/ui gray palette
Why: --primary: 0 0% 9% (black). 10 modules each use different inline colors. System looks like 10 separate products.
Fix: Choose one brand accent color, apply via --primary CSS variable, remove per-module color coding.
Command: /impeccable colorize

### [P2] Hero-metric template on dashboard
Why: Absolute ban — big number + colored icon background + trend badge. Wrong register for factory floor.
Fix: Replace with actionable status: "3 work orders pending" with link. Remove gradient icon backgrounds.
Command: /impeccable shape dashboard

### [P2] Empty states have no guidance
Why: "ไม่มีข้อมูล" appears everywhere. Users cannot tell: (a) data load failed, (b) no data exists, (c) filter is hiding results.
Fix: Every empty state needs: icon + reason title + next action CTA.
Command: /impeccable onboard
